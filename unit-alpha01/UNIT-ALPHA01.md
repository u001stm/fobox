# UNIT α01 / LUMIO 4.21.1-unit-alpha01

Отдельная экспериментальная среда. Рабочая версия LUMIO 4.20.1 и её каталог не заменяются. Разработка в `feature/unit-generator`; опубликованный frozen-релиз не изменяется.

## Запуск

Двойной клик по `Запустить UNIT alpha01.bat`. Среда UNIT выбирается через знак U в левом верхнем углу. Новая съёмка — кнопка +. Альфа открывается на http://127.0.0.1:8776 с отдельным каталогом `%USERPROFILE%\.lumio-unit-alpha01\lumio.sqlite3`.

При первом запуске на этом компьютере туда скопирован рабочий каталог через SQLite backup. Изменения в альфе не возвращаются в основной каталог автоматически. Исторические съёмки доступны в общей статистике копии. Все новые съёмки альфы сохраняются после перезапуска.

## Уже работает

- Импорт RAW и JPEG через существующий импортёр и встроенные RAW-превью. Идентификаторы UNIT отделены от школьных съёмок с той же карты.
- Компактные вертикальные карточки S/M/L, отдельная галочка выбора, увеличение кликом, колесо масштаба, перемещение и двойной клик для вписывания.
- Ручной отбор, раздел брака без удаления, сохранение после обновления, отмена последних изменений в текущей вкладке.
- Свободная перестановка карточек в сборке. Исходные имена сохраняются. Аудио/видео через путь или окно выбора; браузер воспроизводит поддерживаемые им кодеки. Неподдерживаемые форматы можно экспортировать без перекодирования.
- Время по связанному исходному кадру, текстовые слайды. Время берётся из импортированного capture_at; если EXIF отсутствовал, прежний импортёр использует время файла — это не подтверждённое время затвора.
- Обнаружения лиц на всех кадрах, группировка всех достаточно надёжных лиц внутри одного снимка/съёмки. Два лица в одном кадре не объединяются. Группы открываются для просмотра исходных кадров.
- Уникальные люди — **оценка**, а не точный счётчик. Для идентичности отбрасываются лица с confidence < 0.8 и высотой < 7% кадра; их обнаружения остаются в общем счётчике. Порог совпадения по умолчанию 0.45. Маленькие лица в толпе и ракурсы могут быть пропущены/разделены. Число людей между съёмками не складывается.
- Density по 10-минутным интервалам, включая пустые интервалы. Цветовые палитры и гистограммы анализируют превью всех кадров. Это предварительная схема α01, не окончательный утверждённый макет Generator. STATISTICS хранится вне клиентского экспорта в каталоге приложения и может сопровождать выдачу.
- Подключение обработанных JPEG по исходным именам. Неоднозначные совпадения не угадываются; изменения/исчезновение файлов блокируют выдачу.
- Одна кнопка экспорта внизу слева. Яндекс.Диск / компьютер, диск открыт первым. Финальный экспорт требует обработанные JPEG; явный режим «Черновик» разрешает встроенные RAW-превью. Это не полноценная проявка RAW.
- Сквозные номера 001, 002… для фото, текста, времени, аудио и видео. Каждый экспорт в новой папке; видео и аудио копируются без изменения содержимого. MANIFEST содержит соответствия и SHA256. XMP не создаётся.
- Облачный экспорт использует существующий клиент Яндекс.Диска и проверяет размер/MD5; автоматически ничего не загружается. Для UNIT настройте авторизацию и отдельную папку. Реальная облачная передача в рамках разработки не запускалась.
- Общая статистика копии каталога и каналы: UNIT, модели, Стартап Фото, Выпуск, Crous, другое. Подготовка JSON для ULS в локальную outbox. Статус pending: **автоматической синхронизации с ULS пока нет**.

## Проверка

`py -3 -m unittest test_unit_workspace test_lumio -q`

Браузерная проверка проводится отдельно на синтетических вертикальных кадрах TEST. Снимок тестового интерфейса не является подтверждением художественного отбора реального репортажа. Превью реального RAW и подсчёт по сохранённым реальным эмбеддингам проверены дополнительно без изменения основного каталога.

Офлайн-каталог добавлен в 4.21.1: постоянные превью, JSON-снимки и проверяемое восстановление оригиналов. См. OFFLINE-CATALOG.md.
