# LUMIO 4.20.2 — съёмка остаётся без карты

Локальная SQLite-база остаётся основным хранилищем отбора. Дополнительно для каждой съёмки автоматически сохраняются:

```
%USERPROFILE%\.lumio\projects\<ID съёмки>\
    project.json
    previews\*.jpg
```

В UNIT α01 аналогичная папка находится в `%USERPROFILE%\.lumio-unit-alpha01\projects\`.

`project.json` содержит съёмку, список файлов, отбор, роли, подтверждения, историю выбора, данные лиц и UNIT-сборку (если есть). Глобальные настройки, профили и OAuth-токены в JSON не копируются. Это дополнительный читаемый снимок; работа приложения продолжается из SQLite. Кнопки восстановления удалённой базы из JSON пока нет.

Превью сохраняются отдельно от временного кэша, по ID съёмки. Фон сохраняет ориентированные JPEG до 1280 px по длинной стороне. Пока есть карта, приложение постепенно готовит все кадры. Рядом с шапкой отображается готовность: **645/645** означает, что все эти кадры доступны для просмотра без карты. Если часть исходников исчезла раньше, недостающие превью не могут быть созданы без повторного подключения.

Можно извлечь карту, просматривать сохранённые кадры, продолжать отбор и менять роли. Отбор и подтверждения не сбрасываются. Последний человек/вкладка/прокрутка сохраняются в браузере. Школьные данные и UNIT-сборка остаются раздельными.

Офлайн-превью — **не резервная копия RAW**, не полноценное разрешение для печати и не финальная обработка. Экспорт оригиналов проверяет исходники. Программа не подставляет превью вместо RAW незаметно.

## Повторное подключение

- Карта распознаётся по сохранённым отпечаткам файлов, а не по одному пути `D:\DCIM` или совпадению имён.
- Уверенно распознанная единственная съёмка открывается автоматически. При нескольких подходящих проектах предлагается выбрать. Текущий импорт/экспорт или открытое окно редактирования автоматически не закрываются.
- Если это другая карта, старый проект остаётся на месте, а новая карта предлагается для отдельного импорта.
- Если буква диска или папка изменились, откройте статус карты → «Восстановить связь» и выберите папку с теми же файлами. Проверяются все зарегистрированные оригиналы; неполный/другой набор не принимается. Логические пути в отборе не переписываются.
- В стартовой версии отпечатки используют размер, первые и последние 64 KiB файла. Это быстрый способ распознавания содержимого, не полная криптографическая проверка каждой части RAW. Перед копированием выбранный оригинал проверяется ещё раз.

## Автооткрытие в Windows

Лёгкий наблюдатель запускается при входе пользователя, поддерживает локальный сервер и реагирует на появление карты. Если страница LUMIO открыта, событие обрабатывается в ней; если закрыта — открывается браузер с распознанной съёмкой. Приложение остаётся локальным, облачные действия не запускаются.

Файлы: `card_watch.py`, `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\LUMIO Card Watch.vbs`. Отключение: статус карты → «Выключить автооткрытие». Это удаляет собственную запись автозапуска и останавливает наблюдатель после очередной проверки.

При необходимости кнопка «Паспорт JSON на карту» создаёт небольшой `.LUMIO.json` в папке съёмки. Он содержит ID и название, но не заменяет локальную базу и проверку оригиналов. Автоматически служебные файлы на карту не записываются.

Проверены программные сценарии отключения/возврата тестовой папки, чужой карты с такими же именами, другого пути, сохранения отбора и экспорта после восстановления. Реальная физическая перестановка SD и повторный вход Windows требуют пользовательской проверки.
