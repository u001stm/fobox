# LUMIO 4.22.1 · UNIT processing α01

Новая среда в существующем переключателе: **UNIT · обработка α01**. Проверяемый локальный импорт с нескольких карт, отбор, настоящая RAW-проявка, сохранённые параметры, мультимедийная сборка и существующий экспорт. Подробности и ограничения: [UNIT-PROCESSING.md](UNIT-PROCESSING.md).

Запуск: «Запустить UNIT alpha01.bat». Функции: UNIT-ALPHA01.md. Работа без карты: OFFLINE-CATALOG.md. Каталог и исходники съёмок не входят в репозиторий.
