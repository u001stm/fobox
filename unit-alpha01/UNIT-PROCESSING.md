# UNIT · обработка α01 · LUMIO 4.22.1

Добавочная среда на том же сервере и в том же интерфейсе, рядом с Выпуск/Crous/UNIT. Переключение — кнопка U/V/C слева сверху. Прежние проекты и школьные комплекты не переводятся в новую среду автоматически.

## Рабочий путь

1. Новая съёмка → папка с карты. Копирование на компьютер, полный SHA-256 и перечитывание копии. Затем каталог/превью. Исходники карты не изменяются.
2. Все материалы / Отбор: выбор только галочкой; картинка открывается крупно. Технические флаги — подсказки, не автоматическое удаление и не обязательный процент отбора.
3. «Добавить другую карту» пополняет эту же съёмку. Идентификатор проекта постоянный. Одинаковые имена с разными байтами не заменяют друг друга; полные совпадения не копируются повторно.
4. RAW-коррекция: экспозиция, camera/auto WB, теплота, контраст, длинная сторона. Применение к одному кадру или выбранным. Настройки применяются по кнопке, результат сохраняется локально.
5. Сборка: перестановка фото, время соседнего кадра, текст, аудио, видео. Экспорт в одной точке слева снизу: Яндекс.Диск / компьютер. Для проявленных JPEG сохраняются байты и ICC, без повторного JPEG-сжатия.

## Технические границы α01

- RAW: отдельный Python runtime, rawpy/LibRaw, 16-bit TIFF-мастер с ICC, JPEG sRGB до 5000 px по умолчанию. Обработка оригинала, не извлечение камерного preview. Меньшие кадры не увеличиваются.
- Это начальная проявка, не аналог всех возможностей ACR: нет авторской AI-автокоррекции экспозиции, автоматического согласования цвета разных сцен, локальных масок и ретуши. Auto WB — алгоритм RAW-движка, его нужно проверять.
- Очередь импорта/проявки/лиц хранится в SQLite. После перезапуска незавершённые задания запускаются заново с проверкой уже готовых файлов. Ошибку можно повторить. Текущий незавершённый файл читается заново.
- Основные данные, managed originals, previews и render recipes — на компьютере рядом с каталогом, в `unit-processing`. Превью/отбор работают без SD. Это не отдельная резервная копия компьютера.
- Лица: buffalo_l или antelopev2, отдельная экспериментальная настройка среды; detector input до 1280, узнавание локально через ONNX CPU. Новый пакет загружается один раз, проверяется SHA-256. Antelopev2 не объявляется доказанно лучшей моделью на всех съёмках. CUDA ещё не подключена.
- Уникальные люди — оценка кластеризации, а не гарантированное число. Ручные исправления групп пока не реализованы. Для сравнения нельзя переносить старые embeddings между разными recognizer-пакетами; повторный запуск очищает признаки только этой съёмки.
- Статистика и ULS outbox наследуются от UNIT α01; подтверждённого получателя ULS пока нет. Платные API/облачная AI-обработка не включены.
- Видео и аудио копируются без преобразования. JSON/внутренние каталоги не публикуются в GitHub. XMP не создаётся.

## Установка из исходников

Обычный запуск `Запустить UNIT alpha01.bat`. Для RAW один раз `Установить RAW-движок.bat`: он создаёт `.lab-runtime` и устанавливает закреплённые версии из `lab-requirements.txt`, не меняя глобальный Python. Runtime и модели не коммитятся. Рабочие каталоги пользователя в исходники не входят.

4.20.1-frozen и директории старых рабочих версий сохраняются. Эта версия публикуется отдельной веткой/тегом, не заменяет замороженный тег.
