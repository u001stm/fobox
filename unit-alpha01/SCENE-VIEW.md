# 4.22.2 · изолированный просмотр сцен

- «Комплект / Вся серия» — единый сегментированный переключатель с общей рамкой.
- Клик по заголовку сцены ограничивает страницу этой сценой. Переключение между комплектом и серией сохраняет фильтр. «Все сцены» снимает его.
- Открытие основного или дополнительного группового/репортажного кадра показывает полную связанную сцену, включая невыбранные кадры. Лента, стрелки и сравнение остаются в её пределах.
- «Выбрать дополнительные» переходит к той же сцене. Выбор фотографий и их роли не меняются при навигации.
- При отсутствии принадлежности к сцене просмотр ограничивается самим кадром, а не всем репортажем.
- Заголовки строк основных/дополнительных кадров не закрепляются при прокрутке, поэтому не перекрывают соседние строки.

Проверка на отдельной копии реального каталога: сцена 4, открытие основного кадра, лента, сравнение, переключение вкладок, снятие фильтра, неизменность отбора. Синтаксис inline JavaScript проверен. После установки прежние таблицы отбора сохранили контрольные суммы. Фото и каталог в GitHub не включены.
