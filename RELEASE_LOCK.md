# LUMIO v4.20.1 — зафиксированная версия

Статус: самая новая на момент публикации 26.10.2026.

Согласованный снимок приложения расположен в `v4/` и закреплён тегом `v4.20.1-frozen`.
GitHub release immutability блокирует изменение архива релиза и перемещение его тега.
Не заменять файлы релиза и не переносить тег на другой коммит.

Новые изменения: отдельная ветка, новый номер версии, новый релиз. Перед изменениями делать копию работающей версии. Пользовательский каталог `.lumio`, фотографии, OAuth-токены и экспортированные заказы не коммитить.

Контрольные суммы исходников: `v4/SHA256.json`. Контрольная сумма архива публикуется в `SHA256SUMS.txt` вместе с релизом.
Проверка перед фиксацией: 52 теста, 51 успешно, 1 пропущен; отрисовка основных интерфейсных сценариев проверена на данных работающей съёмки. Физическая работа камеры и новая облачная загрузка в рамках фиксации не выполнялись.
